# راهنمای دستورات CLI اسپاداک (`npx spadak`)

ابزار CLI اسپاداک به شما اجازه می‌دهد ابزارهای توسعه هوش مصنوعی (مانند Claude Code, Codex, Aider و غيره) را به راحتی به گیت‌وی متصل کنید.

## دستورات اصلی

### 1. پیکربندی Claude Code

```bash
npx spadak setup-claude
```

این دستور تنظیمات Claude Code را به طور خودکار به سرور Spadak متصل می‌کند.

### 2. اجرای سریع و بدون ثبت (Zero-Persistence Launcher)

```bash
npx spadak launch
```

### 3. عیب‌یابی و بررسی ارتباط

```bash
npx spadak doctor
```
این دستور اتصال کلاینت‌ها به سرور اسپاداک را بررسی می‌کند.
