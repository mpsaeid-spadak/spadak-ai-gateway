# معماری Spadak AI Gateway

**Spadak AI Gateway** یک گیت‌وی پیشرفته و خودمیزبان (Self-hosted) سازگار با APIهای OpenAI است که چندین سرویس هوش مصنوعی را پشت یک توکن یکپارچه `spadak-...` مجتمع می‌سازد.

## اجزای اصلی سیستم

1. **Express Proxy Router:**
   - ارائه اندپوینتهای استاندارد `/v1/chat/completions`، `/v1/models`، `/v1/embeddings` و غیره.
   - مدیریت خطاهای شبکه و ارزیابی پاسخ‌ها.

2. **Fallback Ladder (پلکان بازگشتی):**
   - در صورت رخ دادن Rate Limit یا قطعی در یک ارائه‌دهنده، درخواست بدون وقفه به ارائه‌دهنده سالم بعدی هدایت می‌شود.

3. **رمزنگاری امن (AES-256-GCM):**
   - تمامی کلیدهای API ارائه‌دهندگان در دیتابیس SQLite داخلی رمزنگاری شده و تنها هنگام ارسال درخواست در حافظه (RAM) رمزگشایی می‌شوند.

4. **داشبورد مدیریتی (React 19 + Tailwind CSS):**
   - مدیریت کلیدها، بررسی سلامت مدل‌ها، تحلیل میزان مصرف توکن‌ها و تست مدل‌ها در Playground.
